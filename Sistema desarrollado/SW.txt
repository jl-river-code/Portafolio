PROYECTO: Inversiones Elohim Solution (DM Hub Multi-Tenant)
ARCHIVO: CC3090-inversiones-elohim-solution.zip

El archivo .zip contiene el código fuente completo del sistema y la configuración
de infraestructura lista para levantar con Docker y Docker Compose.

--------------------------------------------------------------------------------
PASOS PARA EJECUTAR LA APLICACIÓN DESDE EL .ZIP
--------------------------------------------------------------------------------

1. Descomprimir el archivo zip:
   unzip CC3090-inversiones-elohim-solution.zip
   cd CC3090-inversiones-elohim-solution

2. Configurar variables de entorno (desde las plantillas provistas):
   cp .env.example .env
   cp backend/.env.example backend/.env
   cp frontend/.env.example frontend/.env

3. Levantar los contenedores:
   docker compose up -d --build

   (Opcional) Mediante el script incluido en la raíz del proyecto:
   ./deploy.sh
