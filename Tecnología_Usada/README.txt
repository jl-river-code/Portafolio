PROYECTO: Inversiones Elohim Solution (DM Hub Multi-Tenant)
CURSO: CC3091 – Ingeniería de Software

DESCRIPCIÓN DE DOCUMENTOS DE TECNOLOGÍAS UTILIZADAS:

1. 03_Seleccion_Persistencia_de_datos.pdf
   - Tema: Selección de la tecnología de persistencia de datos.
   - Descripción: Análisis comparativo entre bases de datos relacionales y NoSQL,
     justificando la elección de PostgreSQL 16 y Entity Framework Core por su
     soporte multi-inquilino, transaccionalidad ACID y tipos JSONB.

2. Tarea investigativa II.pdf
   - Tema: Selección del framework de desarrollo frontend.
   - Descripción: Estudio e investigación sobre Next.js (React), analizando su
     arquitectura híbrida (SSR/SSG), rendimiento web y ventajas para el desarrollo
     del storefront y catálogo del proyecto.

3. Tarea 3 (2)-1.pdf
   - Tema: Herramientas de pruebas y automatización.
   - Descripción: Investigación de frameworks de automatización y testing para
     el stack tecnológico seleccionado, cubriendo pruebas unitarias con xUnit y
     Moq en .NET, así como herramientas para pruebas de componentes.

4. Tarea investigativa Docker.pdf
   - Tema: Herramienta de infraestructura y contenedores.
   - Descripción: Fundamentación técnica del uso de Docker y Docker Compose para
     la contenerización, reproducibilidad del entorno de ejecución y aislamiento
     de servicios (backend, frontend y base de datos).

5. Tecnologias_Usadas.txt
   - Tema: Resumen ejecutivo consolidado de tecnologías.
   - Descripción: Matriz general y justificación rápida del stack completo
     (ASP.NET Core .NET 10, Next.js 16, PostgreSQL 16, Stripe, Nginx y Dokploy).
